# Changelog

## 0.1.0 — 2026-11-02

Initial educational release:

- Dependency-free streaming uniform Monte Carlo integration.
- Explicit sample standard error and approximate normal confidence intervals.
- Private seeded random streams and bounded validation of parameters and outputs.
- Convergence experiments using every prescribed seeded replication.
- Offline square/sine CLI with versioned JSON and no-overwrite output.
- Worked derivation, executed notebook, reproducible static convergence figure,
  numerical/property tests, packaging checks, and CI/release definitions.

This release is authored and technically checked; it has not been learner-piloted
or independently certified. Remote CI status is recorded by GitHub after push.
